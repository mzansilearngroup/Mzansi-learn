# Mzansi Learn & Earn - Grade 9-12 Past Papers & Quizzes

South African learning app for Grade 9, 10, 11 & 12 learners built with React + Supabase.

Learn, practice with past papers, take quizzes and earn rewards.

## How to run
npm install
npm run dev

## Features
- Grade 9-12 Past Papers
- Interactive Quizzes
- Learn & Earn System
- Shop Rewards
